# Customer Segmentation & Behavior Analysis – Online Retail II

## 📊 Project Overview

This Tableau dashboard analyzes customer behavior using **RFM (Recency, Frequency, Monetary)** analysis to identify customer segments such as Champions, Lost Customers, Local Customers, and more.

## 🛠️ Tools Used

- Tableau
- RFM Analysis
- Excel
